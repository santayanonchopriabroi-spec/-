# HMI บนมือถือ — ใช้กับบอร์ดเดิมโดยไม่เปิดคอม

index.html ในโฟลเดอร์นี้เป็นเว็บไฟล์เดียว รวมภาพ/วิดีโอแอร์และส่วนผู้ช่วย AI ไว้แล้ว ใช้ MQTT WebSocket เชื่อมกับ broker เดียวกับ ESP32 ไม่ต้องเปิด START-WINDOWS และไม่ต้องมี VPS เพื่อใช้ปุ่มควบคุมเดิม โทรศัพท์และบอร์ดยังต้องมีอินเทอร์เน็ต โหลด MQTT.js และฟอนต์จาก CDN ตามเดิม

## นำไปใช้จากมือถือ

1. สำรอง index.html เดิมจาก GitHub ก่อนแทนที่
2. ใช้ไฟล์ mobile-web/index.html อัปโหลดแทน index.html ที่ตำแหน่งหน้าเว็บเดิมใน repository GitHub Pages แล้วบันทึก Commit changes จากเว็บ GitHub บนมือถือ
3. เปิด URL ของหน้าเว็บเดิมหลังเว็บอัปเดต ไม่ใช่หน้าดู source บน github.com หากเห็นหน้าเก่าให้รีเฟรชหรือปิดแล้วเปิดแท็บใหม่
4. ถ้า MQTT ไม่เชื่อม ให้เปิด Maintenance แล้วตรวจ Broker WSS, username/password และ Topic Base ให้ตรงกับบอร์ด ค่าที่บันทึกไว้ในเบราว์เซอร์เดิม/โดเมนเดิมยังนำมาใช้ หากเปลี่ยนเครื่องหรือเบราว์เซอร์ต้องตั้งใหม่
5. ใช้บอร์ดและเฟิร์มแวร์เดิมที่เชื่อม HMI ได้อยู่แล้วก่อน ไม่จำเป็นต้องแฟลช V4 เพื่อลองไฟล์นี้
6. ตรวจอุณหภูมิ ไฟหนึ่งจุด แอร์ และถอดไฟบอร์ดตรวจว่าค่าหายและไม่ส่งคำสั่งค้าง

## AI และ Maintenance ขั้นสูง

- ปุ่ม AI อยู่ในเว็บ แต่ยังต้องกรอก URL backend ออนไลน์ที่ตั้งค่าไว้แล้ว ไม่สามารถใส่ API key แล้วให้ static HTML ทำทุกอย่างโดยไม่มี backend
- เข้าหรือออกจาก AI ไม่ตัดการเชื่อมต่อ MQTT เดิม บริการ AI ออฟไลน์ไม่ล้างข้อมูลบอร์ดที่รับโดยตรง
- หากเปิด AI บนคนละโดเมน ให้ตั้ง ALLOWED_ORIGIN ฝั่ง backend ให้ตรง origin ของ HMI เช่น https://your-name.github.io (ไม่ใส่ path /repository)
- บอร์ด V3 เดิมใช้ควบคุมผ่าน MQTT ได้ แต่ฟังก์ชัน AI สั่งงาน/คอนฟิก 54 รายการ/ซอร์สและ build ต้องมี backend และเฟิร์มแวร์ที่รองรับ signed command เหมือนกันตามชุดหลัก
- ถ้าบอร์ดแจ้ง legacyControl=false ระบบจะไม่หลบเลี่ยงข้อกำหนดนี้: ต้องเข้าสู่ backend เพื่อส่งคำสั่งที่ลงนาม การปิดคอมยังทำได้เมื่อ backend อยู่บนเซิร์ฟเวอร์ออนไลน์
- ไมค์จากเว็บใช้งานขณะเปิดเว็บและอนุญาตสิทธิ์ ไม่รับประกันขณะล็อกจอ ดูซอร์ส Android แยกใน android/ หากต้องการทดลองโหมดนั้น

ตรวจด้วย jsdom แล้ว: direct MQTT, ค่า/ภาพแอร์, login/logout AI ไม่กระทบ MQTT, AI offline ไม่ล้างค่า, ไม่ส่งคำสั่งเมื่อข้อมูลบอร์ดเก่า และไม่ข้าม signed-only firmware ยังไม่ได้ทดสอบบอร์ด/มือถือจริงในสภาพแวดล้อมนี้
